# `zenify db-read`

Đọc database dùng chung ở chế độ chỉ đọc, không bao giờ ghi và không in secret.

## Cú pháp

```text
zenify db-read <setup|collections|tables|doc|count|eval|sql> [arg] [flags]
```

## Khi nào dùng

Trước khi viết code chạm một collection, field hoặc bảng. Tên collection và field lấy từ dữ liệu thật, không đoán từ tên model. Skill `/znf:ground` dùng lệnh này.

## Kết quả

Bảy lệnh con:

| Lệnh con | Kết quả |
|---|---|
| `setup` | Mở wizard trong terminal để cấu hình một profile |
| `collections [chuỗi]` | Liệt kê collection Mongo, lọc theo chuỗi con nếu có |
| `tables` | Liệt kê bảng MySQL |
| `doc <collection>` | In một document thật để xem tên field |
| `count <collection>` | Đếm document |
| `eval '<biểu thức>'` | Chạy một biểu thức mongosh chỉ đọc |
| `sql '<câu lệnh>'` | Chạy một câu SQL chỉ đọc |

Lệnh chọn profile bằng `--profile`. Profile mặc định là `staging`; các profile khuyến nghị là `local`, `develop`, `custom` và `production`. Profile không tồn tại hoặc thiếu credential sẽ dừng, không tự chuyển sang `staging`.

Metadata profile nằm trong `.zenify/db-read.json` của workspace. File này chỉ chứa tên biến môi trường và tên database; credential tương ứng nằm trong khối `env` của `.claude/settings.local.json` hoặc trong environment của process.

Chạy `zenify db-read setup` để chọn profile và nhập các tham số trong terminal. Có thể cố định profile trước khi mở wizard bằng `--profile`. URI Mongo và password MySQL được nhập qua ô masked. Khi chạy lại setup, để trống một credential sẽ giữ giá trị hiện có; nếu key đó chưa có giá trị thì setup dừng trước khi ghi file. Profile `production` luôn yêu cầu xác nhận trước khi lưu.

```json
{
  "profiles": {
    "staging": {
      "mongo": { "uriEnv": "MONGO_URL", "database": "app_staging" },
      "mysql": {
        "hostEnv": "MYSQL_HOST",
        "portEnv": "MYSQL_PORT",
        "userEnv": "MYSQL_USER",
        "passwordEnv": "MYSQL_PASSWORD",
        "database": "acd_staging"
      }
    },
    "production": {
      "mongo": { "uriEnv": "MONGO_URL_PRODUCTION", "database": "app_production" }
    }
  }
}
```

`eval` và `sql` chặn các động từ ghi phổ biến để tránh thao tác nhầm. Đây là guard bổ sung; mọi profile, đặc biệt `production`, phải dùng tài khoản DB chỉ có quyền đọc.

## Ví dụ

```bash
zenify db-read setup
zenify db-read --profile local setup
zenify db-read collections chatbot
zenify db-read --profile develop collections chatbot
zenify db-read --profile production doc chat_rooms
zenify db-read doc chat_rooms
zenify db-read sql 'DESCRIBE agents'
```

## Lưu ý

Mỗi lần chạy, lệnh in profile, DB engine và tên database đã chọn nhưng không in host hoặc credential. `production` chỉ được chọn bằng `--profile production`; Git branch không tự đổi profile.

## Cờ

| Cờ | Ý nghĩa |
|---|---|
| `--profile` | database profile: staging, local, develop, custom, or production (mặc định `staging`) |
