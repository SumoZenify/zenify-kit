# `zenify docs`

Nhóm lệnh cho docs layer: đồng bộ knowledge store và sinh trang tham chiếu.

## Cú pháp

```text
zenify docs
```

## Khi nào dùng

Bạn hiếm khi gõ nhóm này. `docs sync` chạy tự động qua hook ở đầu và cuối mỗi lượt. `docs gen` dành cho người sửa kit và CI.

Nền tảng: [Knowledge store](/concepts/knowledge-store) và [Ba lớp của kit](/concepts/three-layers).

## Lệnh liên quan

- [zenify](./zenify): Binary dòng lệnh của ZenifyKit, chứa mọi lệnh workspace và plugin skill đi kèm.
- [zenify docs gen](./zenify_docs_gen): Sinh các trang tham chiếu của website này từ binary, hoặc kiểm tra trang đã sinh còn khớp.
- [zenify docs sweep](./zenify_docs_sweep): Dọn knowledge store - xóa plan, handoff, reference đã hết giá trị và ghi header trạng thái cho spec; mặc định chỉ in kế hoạch.
- [zenify docs sync](./zenify_docs_sync): Đồng bộ knowledge store với remote qua git và dựng lại view docs/ trong workspace.
